# v1 Agents

The first release extends or provides exactly these CLI harnesses: `grok`, `muse-code`, `claude-code`, `codex`, `opencode`, `antigravity-cli`, `pi-coding-agent`. Nothing else (aider, editor forks, brew GUIs). A closed list is what makes inherit-by-default implementable; an open-ended “every CLI” matrix does not ship.
